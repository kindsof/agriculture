    ABOUT THE ATLAS

    关于这张地图

    “中华农耕文化地图”把散落在各地的传统农耕系统、农事习俗与农业文化遗产放到同一张可交互地图上。左侧可按类别、省份和关键词筛选，点击地图地标或列表条目查看详情。

    数据来源

    站点名录与认定年份参考农业农村部“中国重要农业文化遗产”名录、联合国粮农组织“全球重要农业文化遗产”名录、中国非物质文化遗产网、世界灌溉工程遗产名录等公开资料；每个站点在详情中列出对应来源。

    坐标与边界

    站点坐标取县域或乡镇中心，精确到小数点后两位，仅用于地图定位示意，不代表遗产地精确边界。省界数据来自阿里云 DataV.GeoAtlas，地图边界不作为主权或行政界线依据。

    内容说明

    介绍文字为编者根据公开资料综述，力求准确但难免疏漏；遗产名称、认定年份与习俗细节请以原始资料为准。欢迎在仓库中提交修订。

    技术

    纯静态前端 + Python 标准库服务，地图使用 Leaflet，无第三方追踪。运行 python3 web/server.py 即可在本地打开。
